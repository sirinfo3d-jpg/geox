# تطبيق إدارة المشاريع (ProjectFlow Manager)

تطبيق ويب حديث واحترافي باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL)، مخصص لإدارة المشاريع والعملاء وتوزيع المهام على أعضاء الفريق.

تم بناء التطبيق باستخدام بيئة **Next.js 15** و **Tailwind CSS** مع تخزين البيانات محلياً في المتصفح (**LocalStorage**) لضمان سرعة التشغيل الفوري دون الحاجة لضبط أي قواعد بيانات خارجية أو سيرفرات مستقلة.

---

## الميزات الرئيسية

- **لوحة التحكم (Dashboard)**:
  - إحصائيات فورية وتفاعلية: إجمالي المشاريع، المشاريع قيد التنفيذ، المشاريع المكتملة، إجمالي الإيرادات المالية.
  - جدول يعرض أحدث المشاريع وحالاتها للوصول السريع.
  - قائمة أعضاء الفريق الفعّالين ومؤشرات مالية إضافية كمتوسط تكلفة المشروع.

- **إدارة أعضاء الفريق (Team Page)**:
  - إضافة، تعديل، وحذف أعضاء الفريق.
  - تخصصات وأرقام تواصل مسجلة لكل عضو لتسهيل إسنادهم.
  - البحث الفوري عن الأعضاء باسم العضو أو التخصص.

- **إدارة المشاريع (Projects Page)**:
  - قائمة بكل المشاريع مع محرك بحث وخيارات تصفية بحسب الحالة.
  - إضافة وتعديل المشاريع ببيانات متكاملة: اسم المشروع، العميل، رقم التواصل، تواريخ الاستلام والتسليم المتوقعة، رابط مجلد Google Drive، وملاحظات مخصصة.
  - **نظام تسعير مرن**:
    - **خيار السعر الثابت (Fixed Price)**: إدخال قيمة تعاقدية واحدة للمشروع.
    - **خيار التسعير بالمهام (Task-Based Pricing)**: إضافة عدد غير محدود من المهام المحددة بأسعار مستقلة، مع قيام النظام باحتساب إجمالي تكلفة المشروع تلقائياً وتحديثه.
  - تعيين وتحديد متعدد لأعضاء فريق العمل المتاحين للمشروع.

- **صفحة تفاصيل المشروع (Project Details)**:
  - تفاصيل العميل، التكلفة، وروابط الملفات.
  - **مؤشر نسبة الإنجاز التفاعلي (Progress Bar)**: يُحسب تلقائياً وبدقة كنسبة مئوية بناءً على المهام الفرعية المكتملة.
  - **إدارة المهام الفرعية**: إمكانية تغيير حالة المهام (لم تبدأ، جاري التنفيذ، مكتملة) بنقرة واحدة ورؤية نسبة الإنجاز والتكلفة تتحدث مباشرة وبسلاسة.
  - تحديث حالة المشروع ككل من القائمة المنسدلة.

---

## التقنيات المستخدمة

- **الواجهة الأمامية (Frontend)**: Next.js 15 (App Router), React 19, TypeScript
- **التنسيق والتصميم (Styling)**: Tailwind CSS (RTL layout)
- **الأيقونات (Icons)**: Lucide React
- **تخزين البيانات (Persistence)**: LocalStorage (حفظ محلي آمن في المتصفح)

---

## متطلبات التشغيل والتثبيت

لتشغيل هذا التطبيق على جهازك المحلي، تأكد من تثبيت **Node.js** (الإصدار 18 أو أحدث).

### خطوات التشغيل:

1. **تثبيت الحزم البرمجية (Dependencies)**:
   افتح مبنى الأوامر (Terminal) في مجلد المشروع ونفذ الأمر التالي:
   ```bash
   npm install
   ```

2. **تشغيل سيرفر التطوير (Development Server)**:
   بعد انتهاء التثبيت، قم بتشغيل التطبيق محلياً بالأمر:
   ```bash
   npm run dev
   ```

3. **فتح التطبيق في المتصفح**:
   افتح المتصفح على الرابط الموضح في شاشتك (غالباً ما يكون):
   [http://localhost:3000](http://localhost:3000)

## هيكل الملفات الرئيسي

- `app/layout.tsx`: ملف التنسيق العام للتطبيق، ويحتوي على ضبط خط **Cairo** المتميز من Google Fonts وضبط اتجاه الصفحة للغة العربية (`dir="rtl"`).
- `app/globals.css`: ملف التنسيقات العامة والـ CSS.
- `app/page.tsx`: صفحة لوحة التحكم الرئيسية (Dashboard).
- `app/team/page.tsx`: صفحة إدارة وإضافة أعضاء الفريق.
- `app/projects/page.tsx`: صفحة المشاريع الرئيسية وجدول البيانات ونموذج التسعير والتعيين.
- `app/projects/[id]/page.tsx`: صفحة تفاصيل المشروع والتحكم في المهام وتحديث الحالات.
- `components/Sidebar.tsx`: شريط التنقل الجانبي الأنيق والمتجاوب (Responsive) مع الموبايل.
- `hooks/useLocalStorage.ts`: هوك مخصص لإدارة وحفظ البيانات في LocalStorage، ومزوّد ببيانات تجريبية أولية (Seed Data) عند تشغيل التطبيق لأول مرة لتسهيل معاينة الميزات وتجربتها.
- `types/index.ts`: ملف تعريف هياكل البيانات بلغة TypeScript.
